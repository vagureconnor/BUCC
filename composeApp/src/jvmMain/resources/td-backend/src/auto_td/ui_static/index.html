使用说明

完成一次打卡

  1. 连接北航校园网直连。次数查询和官方页面均需要校园网环境。
  2. 在有效时段内点击“打卡”或“打卡三次”，应用会依次发送对应次数的入口和出口请求，保留入口后等待与出口后冷却，并在之后刷新健康云次数。
  3. 不在有效时段时，打卡会失败，后台也会关闭。
  4. 今日次数按健康云后台当天标为有效的出口记录统计。请求结果不会触发自动重发。
