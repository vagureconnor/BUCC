# 纸飞机

纸飞机页面以积分、金币、今日投掷/浏览次数和一键操作为主；出现必要条件不满足或结果不明确时显示错误。课程与课堂感受判断、教师选择、五次串行投掷和浏览由一键流程内部处理，不向用户展示手动选课或选教师控件。SPOC 请求依赖授权会话、CAS RoleCode，并使用加密请求体。官方静态脚本、只读实网查询和 BUCC mock 分开记录。

## 当前一键流程与只读实网证据

一键流程在内部处理课堂和必要的首次课堂感受，并按官方返回顺序使用第一位授课教师。需要投掷时以匿名方式串行执行五次，再进入纸飞机浏览；不提供手动课程/教师选择控件。遇到重复匹配、关键字段缺失、规则不明确或写入结果不明时显示必要错误，不猜测，也不自动重试。页面不展示教师姓名、个人课程、积分值或实际计数之外的诊断数据。

本轮已通过授权 BUCC app 会话进行只读查询：CAS RoleCode 与纸飞机任务接口均有成功响应。任务响应字段名包括 `gzmc`、`num`。已确认的两个任务标签字面值分别是 `投掷“课堂纸飞机”` 和 `浏览“课堂纸飞机”`，其中中文引号本身属于标签字符串。此前严格按不含引号的文本匹配会漏掉任务；当前规范化仅移除这些中文引号字符。若规范化后仍匹配到重复任务，仍报错，不任选一项。个人积分、今日次数及其他账号字段值不记录。

上述 Agent 实网探测只读，只证明本次授权会话中的 CAS role/task 查询成功；Agent 未执行投掷或浏览/查看标记写入。用户之后反馈自行投掷一批成功，但查看失败且耗时较长；这是用户操作反馈，不是 Agent 的实网验收，也不记录本次数、积分或账号值。加油、回复和浏览标记仍属于独立写操作；首页不以此判定作业完成。

本地回归曾以两类响应复现失败：`sfyjl` 数字解析异常，以及成功但 nullable 回执带空格时被误判失败。修复后对应针对性测试通过（RED→GREEN）；减少重复 prepare 和积分轮询也已实现并通过模拟验证。`PaperPlaneApiTest` 的 26 项通过，包含“前 20 条已查看后翻到第二页”的覆盖。以上仅为本地测试，不能据此声称实网投掷或查看写入已验收。

## 证据边界与待验证项

官方页面静态脚本提供 endpoint、字段和调用顺序证据；BUCC 的只读实网探测确认本次 CAS role/task 查询成功；针对性本地回归覆盖上述解析修复。用户反馈自己投掷一批成功、查看失败且慢，但 Agent 没有进行实网写验收；课堂感受和浏览标记写入也未由 Agent 验证。
